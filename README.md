# dugout

**The Dugout** — A story-driven football management visual novel set in the English football pyramid.

## About
Built with React 19, TypeScript, Tailwind CSS, Phaser 3, inkjs, and Zustand. Follow the rags-to-riches journey of a first-time manager battling relegation, debt, and dark secrets at Calder Vale Town FC in Lancashire.

## Features
- **Graphic Novel Noir UI**: Gritty atmosphere, rain simulation, retro typography, and tactile sound effects.
- **Illustrated Character Portraits**: Dynamic mood expressions for key characters (Eddie Marlowe, Arthur Pendelton, Terry Moss, Maya Higgins).
- **Match Engine**: Deterministic seeded simulation with live 2D pitch animations and commentary.
- **Interactive Mini-Games**:
  - Pre-Match Team Talk (Motivation vs Pressure mechanic)
  - Press Conference (Live reactions from Board, Fans, and Squad)
- **Local Persistence**: IndexedDB autosave and save management.
